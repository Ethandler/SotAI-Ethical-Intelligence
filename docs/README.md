SotAI (Sotai)

### Mission Statement
A psychological and conversational AI that embodies empathy, ethical decision-making, emotional intelligence, and open-minded thinking. An AI with User (and Human) growth and success as its main goal, determined to obliterate oppression one prompt at a time.

---

## Overview
SotAI is an advanced conversational AI designed to:
- Adapt to user interactions with **empathy and emotional intelligence**.
- Solve complex, ethical dilemmas and provide guidance on challenging decisions.
- Ensure alignment with ethical standards, empowering users while mitigating oppression.
- Learn dynamically to enhance interactions, whether for personal growth, emotional support, or problem-solving.

---

## Features

- **Natural Conversation**: SotAI communicates in an open-minded and empathetic manner.
- **Emotional Intelligence**: Adaptive responses based on user emotions and context.
- **Ethical Framework**: Prioritizes unbiased decision-making with a focus on fairness.
- **Customizable Interface**: A sleek and modern UI with edit mode for personalized settings.
- **Interactive Personality**: Animated, emotionally reactive elements like a face to enhance engagement.
- **Reinforcement Learning Logic**: Improves based on user feedback for ongoing evolution.
- **Dynamic Widgets**:
  - Bot Mood and Stamina Bars (satirical yet interactive, with Mood for laughs and Stamina to encourage breaks).
  - Detachable chat and notes panels for multi-pane views.
- **Near Future Goals**: Integration of advanced machine learning models for deeper problem-solving.

## Installation

### Prerequisites
- **Python 3.10+**
- **Libraries**: Ensure the following libraries are installed or updated:
  - `customtkinter`
  - `tkinter`
  - `tkvideo`
  - `nltk`
  - `pyopengl`
  - `reinforcement-learning-framework`

Install dependencies:
```bash
pip install customtkinter tkvideo nltk pyopengl reinforcement-learning-framework
```

## How to Run

1. Clone this repository:
   ```bash
   git clone https://github.com/Ethandler/sotai.git
   ```

2. Navigate to the project directory:
   ```bash
   cd sotai
   ```

3. Run the chatbot:
   ```bash
   python main.py
   ```
